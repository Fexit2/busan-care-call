# 한통돌봄 · 부산 에코델타시티 돌봄 접수·우선방문 (기획 시연 웹)

국토교통부 「2026 국가시범도시 AI 아이디어·기술 공모전」 Track 01, 서비스 6-2(부산) 제안용 **동작하는 시연 웹**입니다.
어르신이 단축번호로 거는 전화 한 통이 현장 생활지원사의 오늘 방문 순서가 되는 과정을 세 화면으로 보여 줍니다.
빌드 도구도 서버도 없이 정적 파일만으로 돌아가고, 폴더를 그대로 올리면 배포됩니다.
지도는 에코델타시티 **실제 좌표**이고, 접수 건·통화 내용·긴급도는 **시연용 시나리오 값**입니다.

## 1. 실행

```bash
cd deploy/busan-care-call
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 (모바일 390×844 기준)
```

- `index.html`을 `file://`로 열어도 동작합니다. 데이터를 `data/bundle.js`로 넣었기 때문입니다.
- 지도 타일은 OpenStreetMap을 실시간으로 받습니다. 네트워크가 없으면 타일만 빠지고 마커와 동선은 그대로 보입니다.
- 외부 CDN을 쓰지 않습니다. Leaflet은 `vendor/leaflet`에 있고 글꼴은 기기 기본 서체를 씁니다.

## 2. 화면 (3개)

| 탭 | 내용 |
| --- | --- |
| **오늘의 방문** | 오늘 접수·적색·황색·방문 완료 KPI, 단지 지도(우선방문 1~5번, 동선 6.2km·13분, 나머지 단지는 점), 긴급도와 반복 접수로 정렬한 우선방문 목록. 카드를 누르면 사유와 권장 조치가 열리고, 배정과 방문 완료를 한 번에 바꿉니다 |
| **전화 접수** | 어르신이 단축번호를 누르는 상황 3종(건강 이상 / 보일러·생활민원 / 약·병원 동행). 통화가 흐르고 사투리 문장이 한 줄씩 쌓인 뒤, AI가 정리한 티켓(증상, 확인한 것, 긴급도, 추천 조치, 배정)이 뜹니다. `오늘 목록에 넣기`를 누르면 맨 위에 올라갑니다 |
| **연계 · 근거** | 접수 한 건이 오늘의 방문이 되기까지 5단계, 이어 붙이는 기록(스마트빌리지 통합관제, 응급안전안심서비스, 노인맞춤돌봄, 119, 행정복지센터), 실측과 시연 값 구분표, 기대효과, 한계 고지 |

상단 `● DEMO · 기획 시연용` 배지는 지우지 않습니다.

## 3. 데이터

- `data/bundle.js` (`window.__CARE__`, 약 7KB) — 단지 좌표·세대수, 오늘 접수 11건, 오늘 오전 동선
- 생성: `tools/build_bundle.py`. 동선은 OSRM 도로 경로를 한 번 받아 `tools/route_cache.json`에 두고 재사용합니다.
- 단지 좌표는 공개 지도(OpenStreetMap)에서 읽은 위치입니다. 실제 필지 경계가 아닙니다.
- 행정복지센터까지 거리(12.1km·21분)는 스마트빌리지에서 강동동 행정복지센터까지 도로 경로로 계산한 값입니다.

## 4. 검증

```bash
cd deploy/busan-care-call
LD_LIBRARY_PATH=/workspace/tmp/sysroot/usr/lib/x86_64-linux-gnu python3 tools/verify.py
```

- Chromium 390×844(DPR2)과 1440×900에서 콘솔 에러 0, 페이지 예외 0, 실패 요청 0
- 가로 넘침 0 (오늘·전화·연계, 모바일·데스크톱)
- 지도 마커 10곳과 동선 렌더, 카드 선택, 배정 전환, 통화 3종 재생과 티켓 생성, 오늘 목록 반영 확인
- 스크린샷: `downloads/busan_care_1.png` ~ `busan_care_7.png` (1~3이 핵심 화면)

## 5. 폴더

```
busan-care-call/
  index.html      화면 구조
  styles.css      디자인 (라이트, 모바일 앱형 + 데스크톱 2단)
  app.js          목록·지도·통화 시나리오·티켓 렌더링
  data/bundle.js  시연 데이터 (자동 생성)
  vendor/leaflet  지도 라이브러리
  tools/build_bundle.py  데이터 생성
  tools/verify.py        자동 검증과 스크린샷
```

## 6. 배포할 때

- 정적 호스팅(GitHub Pages 등)에 이 폴더를 그대로 올리면 됩니다. 빌드 단계가 없습니다.
- 공모전 '원본 자료 링크'에는 배포한 주소를 적고, 심사 종료까지 열어 둡니다.
- 익명 심사 대상이므로 이름·소속·연락처를 어디에도 넣지 않았습니다. 가구 정보도 동·호수까지만 표시합니다.
